# Roadmap

1. **Foundation — complete:** project structure, documentation, logging, and a
   runnable Godot project.
2. **World prototype — complete:** terrain, navigation, RTS camera, selectable
   survivor, movement, and a wood node.
3. **Survivor gathering:** add a reusable resource-node contract and let the
   survivor gather wood.
4. **Resource inventory:** centralize wood, stone, and food and expose a basic UI.
5. **Construction:** placement, costs, progress, health, and destruction.
6. **Walker/combat/hordes:** implement and validate each as a separate feature.
7. **Research and ages:** implement the Prehistoric → Stone → Bronze MVP path.
8. **MVP completion:** variants, Bronze Age trial, UI, saves, procedural map,
   feedback, and balancing tools.

Each numbered item is a queue of small deliverables, not permission to implement
multiple major systems in one development session.
