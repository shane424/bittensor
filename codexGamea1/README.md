# Ages of the Dead

This repository contains the Godot 4 project for **Ages of the Dead**, a
data-driven survival/base-building game about advancing civilization while the
undead evolve in response.

## Current playable milestone

The first world prototype intentionally contains only:

- a simple 3D terrain and baked navigation surface;
- an isometric RTS camera;
- one selectable survivor who can move;
- one wood resource node.

Open `project.godot` in Godot 4 and run the project. Left-click the
survivor to select it, then right-click the ground to move. Pan with **WASD**,
zoom with the mouse wheel, and rotate by dragging the middle mouse button.

Later systems (gathering, zombies, research, ages, and crafting) are explicitly
outside this milestone.
